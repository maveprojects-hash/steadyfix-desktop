# STEADYFIX CMMS for computers

The STEADYFIX app in its own window for Windows, Mac and Linux, with built-in network scanning. Included with the PRO plan.

- Opens the same STEADYFIX app, so your phone and computer always show the same data.
- Finds the devices on the local network and shows them under Monitoring.
- Keeps scanning from the system tray when the window is closed. It can start when the computer starts.
- Updates itself when a new version is released.

To publish a new version: change `version` in `package.json`, then create a new release on GitHub with a tag such as `v1.0.1`. The installers are built automatically.
